## ✨ Key Features

- **🎨 Custom Claymorphism UI**: A soft, fluffy, and tactile design system built entirely with vanilla CSS using complex `box-shadow` layers (inset and outset) to create a 3D, embossed feel.
- **👀 Eye-Tracking Character**: A custom JavaScript implementation that makes the hero character's eyes naturally follow the user's mouse cursor across the screen.
- **🆔 Interactive Physics Lanyard**: A draggable, swinging ID card built with vanilla JavaScript physics logic. Grab it and toss it around!
- **🌧️ Matrix Rain Background**: A performant HTML5 `<canvas>` background effect showing a digital rain of numbers that adapts dynamically to screen sizes.
- **✉️ Dynamic Envelope Contact**: A playful CSS interaction where a contact letter slides smoothly out of a physical-looking envelope pocket when hovered or tapped.
- **🎠 Scroll-Snap Carousel**: A buttery smooth, horizontal scrolling project gallery built with native CSS `scroll-snap` for perfect card alignment.
- **📱 App-like Mobile Experience**: Automatically transforms into a mobile-first layout with a fixed bottom navigation bar and dynamically scaling components.

## 🛠️ Tech Stack

This project deliberately avoids heavy frameworks to demonstrate pure frontend craftsmanship, prioritizing lightning-fast load times and granular control over animations:

- **HTML5**: Clean, semantic structure with accessibility (`aria-labels`, `tabindex`) built-in.
- **CSS3**: Advanced usage of CSS Variables, Flexbox, Media Queries, fluid typography using `clamp()`, and intricate shadows.
- **Vanilla JavaScript**: DOM manipulation, Canvas API rendering, `requestAnimationFrame` for physics, and focus-trapping for modals.

## 🚀 Getting Started

Running this project locally is incredibly simple. No `npm install`, no build pipelines, and no bundlers required!

1. Clone this repository to your local machine:
   ```bash
   git clone https://github.com/yourusername/agent-portfolio.git
   ```
2. Navigate to the project directory:
   ```bash
   cd agent-portfolio
   ```
3. Open the `index.html` file in your favorite web browser:
   ```bash
   # On macOS
   open index.html
   
   # On Windows
   start index.html
   ```
